# Security

Please report a vulnerability privately, through GitHub: the **Security** tab
of this repository, then **Report a vulnerability**. Don't open a public
issue for it.

Include what you found, how to reproduce it, and what it lets someone do. We
will acknowledge the report, keep you informed, and credit you when it is
fixed, if you would like.

The SDKs run in your users' browsers and hold no secrets. A report about what
the assistant may see or do is most likely about the Mihe runtime, which
enforces those rules; it is welcome here all the same.
